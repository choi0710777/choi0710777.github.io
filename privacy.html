개인정보처리방침

이 방침은 운영자가 자신의 Google 계정으로 사용하는 개인용 도구인 shorts-factory 자동저장의 데이터 처리 기준을 설명합니다. 공개 이용자를 모집하거나 가입 정보를 받는 서비스가 아닙니다.

현재 연결 준비 및 검증 단계입니다. 아래 내용은 이 개인용 연결의 사용 목적과 운영 기준이며, 실제 서비스 연결의 완료를 의미하지 않습니다.

1. 접근하는 정보와 목적

  • 작업 파일: 사용자가 처리하도록 지정한 영상·텍스트·자막 등입니다. 사용자가 요청한 영상 작업, 결과 보관과 전송 확인에 사용합니다.
  • Drive 파일 정보: 앱에 허용된 파일의 이름, ID, 종류, 크기, 보관 폴더와 체크섬 등입니다. 올바른 위치에 파일이 저장됐는지 확인하기 위해 사용합니다.
  • 작업 기록: 파일 정보, 체크섬, 전송 상태와 확인 결과를 남깁니다. 실패와 완료를 구분하고 사용자가 결과를 확인하는 데 사용합니다.
  • 인증 정보: OAuth 연결에 필요한 클라이언트 설정과 토큰을 사용합니다. Google 계정의 비밀번호를 이 도구나 이 사이트가 수집하지 않습니다.

2. Google Drive 접근 범위

요청 범위는 drive.file 하나입니다. 이 앱이 생성하거나 사용자가 이 앱에 명시적으로 열어 준 파일에 접근합니다. 같은 계정의 파일이라는 이유만으로 모든 Drive 파일에 접근할 수 있는 권한은 아닙니다.

해당 범위에는 허용된 파일을 읽고 생성·수정·삭제할 수 있는 권한이 포함됩니다. 현재 전송 프로그램은 파일을 자동 삭제하지 않습니다. 사용자의 명시적인 지시 없이 Drive의 공개 공유 설정을 변경하지 않습니다.

3. Claude와 Google을 통한 처리

사용자가 선택한 Claude 클라우드 작업 환경에서 영상 처리와 전송을 실행하고, 결과는 사용자의 Google Drive에 저장하는 방식으로 구성합니다. 작업에 필요한 파일과 정보가 해당 서비스에서 처리될 수 있습니다. 각 서비스의 이용 조건과 데이터 처리·보관 정책도 함께 적용됩니다.

인증 갱신 정보는 사용자의 개인 Claude 환경에 있는 네트워크 시크릿으로 보관하고 Google의 인증 토큰 발급 주소에 전달하도록 구성합니다. 전송 프로그램은 발급받은 짧은 유효기간의 접근 토큰을 메모리에서 사용하며, 토큰 값을 작업 결과 기록에 넣지 않습니다.

최초 인증 설정에는 보호된 설정 파일을 사용할 수 있습니다. 인증 파일, 토큰, 계정 식별 정보와 개인 작업 파일은 공개 안내 사이트나 공개 소스 저장소에 게시하지 않습니다.

4. 이용과 제공의 제한

이 도구는 Google 사용자 정보를 광고에 이용하거나 판매하지 않습니다. 사용자가 요청한 개인 영상 작업·보관·확인 목적 외의 독립적인 이용이나 제공을 하지 않습니다. Google API에서 받은 정보는 Google API Services User Data Policy의 제한적 이용 요건을 포함하여 해당 정책에 따라 취급합니다.

5. 보관과 삭제

Drive에 저장된 결과 파일은 사용자가 삭제할 때까지 보관하는 것을 기본으로 합니다. 이 도구에는 결과 파일을 일정 기간 뒤 자동 삭제하는 기능이 없습니다. 작업 기록과 최초 인증 설정 파일은 사용자가 보관 위치에서 직접 관리·삭제합니다. Claude의 작업 공간과 서비스 자체의 기록에는 해당 서비스의 보관 정책이 적용됩니다.

PC에 완성본을 내려받는 작업은 사용자가 명시적으로 요청할 때만 진행합니다. 이미 내려받은 파일은 사용자가 PC에서 별도로 관리합니다.

6. 연결 해제와 권한 철회

작업을 중단하고 Google 계정의 외부 앱 연결 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 사용을 끝낼 때는 Claude 환경의 관련 네트워크 시크릿과 남아 있는 인증 설정 파일도 삭제합니다.

연결 해제만으로 기존 Drive 파일, 이미 생성한 작업 기록이나 PC에 저장한 파일이 삭제되지는 않습니다. 파일 삭제는 각각의 보관 위치에서 별도로 진행합니다.

7. 이 안내 사이트

이 사이트에는 로그인 폼, 광고, 방문자 분석 스크립트나 쿠키를 설정하는 코드가 없습니다. 호스팅 제공자가 서비스 운영을 위해 처리하는 접속 기록에는 해당 제공자의 정책이 적용됩니다.

8. 문의와 변경

운영 관련 연락처는 Google 권한 동의 화면에 표시되는 지원 이메일입니다. 처리 목적·권한·보관 방식이 바뀌면 이 페이지를 수정하고, 새로운 계정 권한이 필요한 경우 Google 동의 절차를 진행합니다.
